# Rebalancer
此扩展可用于配置游戏平衡性的各个方面。

## 用法
此扩展仅接受一个文件作为输入，该文件应为符合扩展内置架构（schema）的 JSON 文件。使用支持 JSON Schema 的文本编辑器有助于编写你自己的平衡性配置文件。

## 建筑放置与姿态
平衡性配置文件中有两个部分会修改游戏代码中的单个数值：

* `building_placement`：每种地图尺寸对应的城堡建造范围（在遭遇战和多人游戏中，城堡建筑最远可离主堡多远建造），以及放置储藏区、粮仓或军械库、攻城帐篷或 AI 城墙时，敌方单位允许靠近的距离。
* `stances`：处于进攻和防御姿态的单位搜索敌人的距离、有多少单位会同时追击同一个敌人，以及处于进攻姿态的近战单位搜索可攻击建筑的距离。

每个键都是可选的。未填写的键会保留游戏原值，Rebalancer 不会改动它。每个数值都会在 Stronghold Crusader 和 Crusader Extreme 中通过其周围的代码定位，且仅在它仍保持游戏原值时才会被写入。如果找不到某个数值，或者其他模块已经修改了它，该设置将被跳过，并在日志中说明原因。架构中列出了每个键的允许范围以及游戏原值。
